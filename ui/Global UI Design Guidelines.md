Global UI Design Guidelines
Color Scheme:

Primary: Blue (#2196F3)
Success: Green (#4CAF50)
Error: Red (#F44336)
Warning: Orange (#FF9800)
Background: Light gray (#F5F5F5)
Text: Dark gray (#333333)

Typography:

Headers: Bold, 14-16pt
Body text: Regular, 10-12pt
Buttons: Bold, 10pt
Monospace: For email addresses and code

Common Elements:

Buttons: Consistent sizing, rounded corners
Input fields: Clear borders, focus states
Progress indicators: Consistent styling
Error messages: Clear, actionable text

Navigation Flow:

Back buttons always available (except on landing)
Clear step indicators
Confirmation dialogs for destructive actions
Keyboard shortcuts for power users (optional)

Error Handling:

Inline validation messages
Clear error states
Recovery suggestions
Non-blocking notifications

This design ensures a smooth, professional user experience while keeping the interface simple and intuitive for your mini CRM application.
